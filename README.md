# Unmark

PDF watermark remover. Runs fully in the browser and installs as a PWA.

## Deploy on GitHub Pages
1. Push everything in this folder to the root of a repo's `main` branch.
2. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)`.
3. Open `https://<user>.github.io/<repo>/` and choose Install / Add to Home Screen.

After changing any file, bump `VERSION` in `sw.js` so installed copies update.
